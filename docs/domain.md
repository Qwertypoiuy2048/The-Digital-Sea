# Domain

The Digital Sea is a 2D game prototype. The intended player is a newly spawned program exploring a dangerous network ecosystem (`Brainstorming.md`). Current implemented domain objects are a player, programs, modules, extensions, network nodes, and connections.

Implemented vertical slice: configure a program on the Code screen and inspect a cached network map on the Network screen. Runtime concepts include compute, memory, cores, compile state, scanner capabilities, cached inventory, node size, connection bandwidth/stability/security, and monitored state.

Brainstorming names future concepts—resource gathering, evolution, territory, hostile programs, Admin patrols, transmission, movement, economy, copies/backups, failure, and social ecology—but their implementation and acceptance criteria are UNKNOWN and not contracts.
